Práticas de segurança

Última atualização: 2 de agosto de 2026.

1. Fonte oficial do instalador

Baixe o Bridge somente por esta página oficial do projeto. Antes de executar o arquivo, confira o hash SHA-256 publicado junto do download.

2. Assinatura digital

O instalador atual ainda não possui assinatura digital de código. Por isso, o Windows pode exibir alertas de reputação ou SmartScreen. Trate esse comportamento como esperado até a distribuição passar a usar code signing.

3. Pareamento

O QR Code de pareamento deve ser gerado localmente no computador e escaneado apenas pelo usuário que controla ambos os dispositivos. Não reutilize QR Codes recebidos de terceiros.

4. Escopo de acesso

Autorize no Bridge apenas as pastas e projetos estritamente necessários. O aplicativo remoto deve operar somente dentro do escopo explicitamente liberado no painel local.

5. Endpoints confiáveis

Mesmo com criptografia em trânsito, a segurança final depende do seu endpoint. Se o computador estiver comprometido, o pareamento também fica comprometido.

6. Resposta a incidentes

Se você suspeitar de uso indevido, revogue o computador pareado no app, desative o Bridge localmente e gere um novo pareamento após revisar o ambiente.
